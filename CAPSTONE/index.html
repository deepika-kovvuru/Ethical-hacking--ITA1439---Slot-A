What affects strength?

A strong password is long, unique, and difficult to guess.

Length beats complexity

Use at least 15 characters. Longer passwords take far more guesses.

Make it unpredictable

Avoid names, dates, familiar phrases, keyboard walks, and simple substitutions.

Keep it unique

Never reuse a password. A password manager can create and remember a different one for every account.

Security checks

Local checks flag common risks. They do not query breach databases.

No live breach lookup is performed. For exposed-password checks, use a reputable service that supports privacy-preserving k-anonymity.
